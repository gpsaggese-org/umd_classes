Cell 2: Hoeffding Inequality: Theoretical Bounds¶

  • The Hoeffding inequality provides a concentration bound
    • It quantifies how quickly the sample mean converges to the true mean as NNN increases

Cell 2.1: Hoeffding Inequality Statement¶

  • For NNN independent Bernoulli random variables X1,…,XNX_1, \ldots, X_NX1​,…,XN​ with probability μ\muμ

  • Let ν=1N∑i=1NXi\nu = \frac{1}{N} \sum_{i=1}^{N} X_iν=N1​∑i=1N​Xi​ be the sample mean

  • The Hoeffding inequality states:

P(∣ν−μ∣≥ϵ)≤2exp⁡(−2Nϵ2)P(|\nu - \mu| \geq \epsilon) \leq 2 \exp(-2N\epsilon^2)P(∣ν−μ∣≥ϵ)≤2exp(−2Nϵ2)
(1)
  • Where:
    • ν\nuν is the sample mean (empirical probability)
    • μ\muμ is the true probability
    • ϵ>0\epsilon > 0ϵ>0 is the deviation threshold
    • NNN is the number of samples

Key insights:

  • The bound decreases exponentially with NNN
  • The bound is independent of μ\muμ (distribution-free)
  • Larger ϵ\epsilonϵ requires larger NNN for the same confidence
  • The factor of 2 accounts for both tails:
    • ν>μ+ϵ\nu > \mu + \epsilonν>μ+ϵ
    • ν<μ−ϵ\nu < \mu - \epsilonν<μ−ϵ

Cell 2.4: Hoeffding Bound as a Function of NNN and ϵ\epsilonϵ¶

  • The Hoeffding bound formula is:
Bound=2exp⁡(−2Nϵ2)\text{Bound} = 2 \exp(-2N\epsilon^2)Bound=2exp(−2Nϵ2)
(2)
  • This interactive visualization shows how the bound changes as we vary NNN and ϵ\epsilonϵ
  • Understanding this relationship is crucial for:
    • Choosing appropriate sample sizes NNN for a desired confidence level
    • Understanding the trade-off between deviation tolerance (ϵ\epsilonϵ) and sample requirements
    • Seeing the exponential decay in both NNN and ϵ2\epsilon^2ϵ2

View modes:

  • Heatmap:
    • Shows the bound value as a color map across all (N,ϵ)(N, \epsilon)(N,ϵ) combinations
  • Fix NNN, vary ϵ\epsilonϵ:
    • See how increasing tolerance (larger ϵ\epsilonϵ) affects the bound
    • For a fixed sample size
  • Fix ϵ\epsilonϵ, vary NNN:
    • See how increasing sample size improves the bound
    • For a fixed deviation threshold
  • Contour plot:
    • Shows curves of constant probability
    • Useful for finding (N,ϵ)(N, \epsilon)(N,ϵ) pairs that achieve the same confidence

Key observations:

  • The bound is exponentially sensitive to both NNN and ϵ\epsilonϵ
  • To halve ϵ\epsilonϵ while maintaining the same bound, you need to quadruple NNN
