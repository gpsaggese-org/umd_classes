Exact Inference in Bayesian Networks

  • This notebook teaches how to compute exact posteriors P(X∣e)P(X \mid \mathbf{e})P(X∣e) in a discrete Bayesian network
  • Concepts are built on the the burglary-alarm network and the query P(Burglary∣JohnCalls,MaryCalls)P(Burglary \mid JohnCalls, MaryCalls)P(Burglary∣JohnCalls,MaryCalls)
  • The flow is:
    • Inference by enumeration (brute force)
    • Variable elimination (caching)
    • Irrelevant-variable pruning
    • Complexity and limits
