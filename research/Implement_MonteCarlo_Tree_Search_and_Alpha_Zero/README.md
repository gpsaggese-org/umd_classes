# Implement Monte Carlo Tree Search and Alpha Zero

This project implements the Monte Carlo Tree Search (MCTS) algorithm and the Alpha Zero algorithm for game playing. [(Plan)](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/research/ideas/draft.Implement_MonteCarlo_Tree_Search_and_Alpha_Zero.md)

## Tutorials

- [`main.ipynb`](main.ipynb): implement rollout-based MCTS for tic-tac-toe
  from scratch.
- [`mctx/`](mctx/): use DeepMind's GPU-accelerated Mctx library to search
  batches of tic-tac-toe positions.
