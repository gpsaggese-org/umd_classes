# Tutorials

This book collects the tool tutorials in `msml610/tutorials/`. Each tutorial
covers one topic used in MSML610 (Advanced Machine Learning): Statistical
Learning, Bayesian Networks, Probabilistic Programming, Causal Inference,
Kalman Filters, Multi-Armed Bandits, Causal Discovery, and Reinforcement
Learning.

Notebooks are re-executed at build time, so their outputs always reflect the
current code.

Pick a tutorial from the navigation to get started.
