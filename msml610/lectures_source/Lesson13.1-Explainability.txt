# Machine Learning Explainability

* Why Explainability Matters

- **Question**: _"A model predicts a patient has 92% chance of heart disease
  $\to$ should the doctor trust it?"_
  - Without explanation, even accurate models are unusable in high-stakes
    decisions

- **Problem**: ML models are increasingly used for decisions that affect
  people's lives
  - Credit scoring, medical diagnosis, criminal sentencing, hiring
  - Stakeholders (doctors, judges, regulators) need to understand _why_ a
    prediction was made, not just _what_ it is

- **Definition**: Explainability (aka _"interpretability"_) is the degree to
  which a human can understand the cause of a model's decision
  - Aka "Interpretable ML", "XAI" (Explainable Artificial Intelligence)

* Accuracy vs Interpretability

- **Key insight**: there is a fundamental tension between model _accuracy_ and
  _interpretability_
  - Linear regression $\to$ interpretable but limited capacity
  - Deep neural networks $\to$ high capacity but opaque (_"black box"_)

- **Goal**: develop methods that explain black-box models _post-hoc_, without
  sacrificing predictive performance

* Taxonomy of Explainability Methods

- **Definition**: explainability methods can be classified along several axes

::: columns
:::: {.column width=55%}
- By _scope_:
  - **Global**: explain the model's overall behavior
    - E.g., feature importance rankings, partial dependence plots
  - **Local**: explain a single prediction
    - E.g., _"why was this loan application rejected?"_

- By _model dependence_:
  - **Model-specific**: exploit internal model structure
    - E.g., attention weights in transformers, decision paths in trees
  - **Model-agnostic**: treat the model as a black box
    - E.g., LIME, SHAP $\to$ work with any model

- By _output type_:
  - Feature attributions (numeric importance scores)
  - Rules or decision sets
  - Example-based (prototypes, counterfactuals)

* LIME: Local Interpretable Model-Agnostic Explanations

- **Key idea**: approximate a complex model _locally_ with a simple,
  interpretable model (Ribeiro et al., 2016)

::: columns
:::: {.column width=55%}
- **Algorithm**:
  1. Pick an instance $\blue{x}$ to explain
  2. Generate perturbed samples $\{z_1, ..., z_N\}$ around $\blue{x}$
  3. Weight each $z_i$ by proximity to $\blue{x}$ using a kernel
     $\pi_{\blue{x}}(z_i)$
  4. Query the black-box model $f$ on all $z_i$ to get predictions $f(z_i)$
  5. Fit a simple model $\red{g}$ (e.g., linear) on $\{(z_i, f(z_i))\}$ weighted
     by $\pi_{\blue{x}}$

::::
:::: {.column width=45%}

- **Example**: a spam classifier flags an email $\to$ LIME reveals the words
  _"free"_, _"winner"_, and _"click here"_ drove the prediction
  - The linear explanation $\red{g}$ assigns a positive coefficient to each of
    these tokens

* LIME: Local Interpretable Model-Agnostic Explanations

- **Formally**:
  $$
  \red{g^*}
    = \arg\min_{g \in G}
        \sum_{i=1}^{N}
          \pi_{\blue{x}}(z_i)
          \left(
            f(z_i) - \red{g}(z_i)
          \right)^2
        + \Omega(\red{g})
  $$
  - $\Omega(\red{g})$ penalizes complexity of the explanation (e.g., number of
    non-zero coefficients)
