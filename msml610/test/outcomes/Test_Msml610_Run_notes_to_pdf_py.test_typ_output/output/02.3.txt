// Styled table with zebra striping, lateral lines, and configurable width.
#let styled-table(headers: (), rows: (), caption: none, col-widths: none, bold-first-col: true, size: 0.8em, width: 80%) = {
  let n = headers.len()
  let widths = if col-widths != none { col-widths } else { (1fr,) * n }

  // Zebra striping: alternate white and darker gray backgrounds on full rows
  let processed-rows = rows.enumerate().map(((idx, row)) => {
    let bg-color = if calc.rem(idx, 2) == 0 { white } else { rgb("#e8e8e8") }
    if bold-first-col {
      (
        table.cell(fill: bg-color, text(fill: black, weight: "bold", row.at(0))),
        ..row.slice(1).map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
      )
    } else {
      row.map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
    }
  })

  text(size: size,
    figure(
      align(center,
        block(width: width,
          table(
            columns: widths,
            align: (left,) * n,
            stroke: none,
            table.vline(x: 0, stroke: 2pt),
            table.hline(stroke: 2pt),
            table.header(
              ..headers.map(h => table.cell(fill: black, text(fill: white, weight: "bold", h)))
            ),
            table.hline(stroke: 1.5pt),
            ..processed-rows.flatten(),
            table.hline(stroke: 2pt),
            table.vline(x: n, stroke: 2pt),
          )
        )
      ),
      kind: table,
      caption: caption,
    )
  )
}

==== Data Processing Transformations
<data-processing-transformations>
- #text(fill: black, weight: "bold")[Purpose of data processing]

  - Prepare raw data for effective machine learning
  - Improve model performance and generalization

- #text(fill: black, weight: "bold")[Data cleanup]

  - Apply filters or smoothing to remove irrelevant variations

- #text(fill: black, weight: "bold")[Handling missing data]

- #text(fill: black, weight: "bold")[Types of transformations]

  - Normalization and standardization
  - Encoding categorical data
  - Feature construction
  - Dimensionality reduction
  - Discretization

- #text(fill: black, weight: "bold")[Data augmentation]

  - Increase dataset size using transformations (common in vision)

==== Data Cleaning
<data-cleaning>
- #text(fill: black, weight: "bold")[Purpose of data cleaning]
  - Ensure data quality for accurate model training
  - Detect and correct errors or inconsistencies in the dataset
- #text(fill: black, weight: "bold")[Typical steps in data cleaning]
  - #emph[Remove duplicates];: Identical records are eliminated
  - #emph[Correct data entry errors];: Fix misspellings or misformatted
    entries
  - #emph[Standardize data];:
    - Convert dates formatted as both #text(fill: blue)[MM/DD/YYYY] and
      #text(fill: blue)[DD-MM-YYYY] into consistent format
    - String normalization (e.g., lowercase conversion)
    - Type conversion (e.g., strings to integers)
    - Dealing with unexpected characters or encodings
- #text(fill: black, weight: "bold")[Relevance to ML models]
  - Poor data quality leads to biased or incorrect predictions
  - Clean data reduces variance and improves generalization

==== Handling Outliers and Missing Data
<handling-outliers-and-missing-data>
- #text(fill: black, weight: "bold")[Outliers]
  - #emph[Definition];: Data points significantly different from others
  - #emph[Causes];: Measurement errors, variability in the data
  - #emph[Detection];: Box plots, Z-scores, or interquartile method
  - #emph[Treatment];: Removal, capping, or transformation (e.g., log
    scale)
- #text(fill: black, weight: "bold")[Missing data]
  - #emph[Detection];: Count of null values or incomplete entries
- #text(fill: black, weight: "bold")[Remediation]
  - #emph[Deletion];: Remove rows or columns with too many missing
    values
  - #emph[Imputation];:
    - Mean/median/mode substitution
    - K-nearest neighbors (KNN)
    - Regression or model-based approaches
    - E.g., for a missing temperature reading, impute using the mean of
      the day's surrounding values

==== Normalization and Standardization
<normalization-and-standardization>
- #text(fill: black, weight: "bold")[Goal];: Adjust feature scales for better convergence and
  learning
  - #emph[Normalize];: Rescale to $\[ 0 \, 1 \]$
  - #emph[Standardize];: Zero mean, unit variance
- #text(fill: black, weight: "bold")[Why it helps]
  - Equal feature contribution in distance-based models
  - Faster convergence in gradient-based algorithms
  - Enables regularization
  - Easier feature interpretation
- #text(fill: black, weight: "bold")[Common methods]
  - Min-Max normalization:
    $x' = frac(x - x_(m i n), x_(m a x) - x_(m i n))$
  - Z-score standardization: $x' = frac(x - mu, sigma)$

==== Encoding Categorical Data
<encoding-categorical-data>
- #text(fill: black, weight: "bold")[Goal];: Convert non-numeric categories into numeric
  representations

- #text(fill: black, weight: "bold")[Label encoding]

  - Assigns an integer to each category
    - E.g., #text(fill: blue)[red], #text(fill: blue)[green],
      #text(fill: blue)[blue] $arrow.r$ #text(fill: blue)[1],
      #text(fill: blue)[2], #text(fill: blue)[3]
  - Can mislead models if order is not meaningful

- #text(fill: black, weight: "bold")[One-hot encoding]

  - Creates binary vector per category
    - E.g., #text(fill: blue)[red], #text(fill: blue)[green],
      #text(fill: blue)[blue] $arrow.r$ #text(fill: blue)[[1,0,0]],
      #text(fill: blue)[[0,1,0]], #text(fill: blue)[[0,0,1]]
  - Avoids ordinal assumption
  - Increases dimensionality

==== Feature Construction
<feature-construction>
- #text(fill: black, weight: "bold")[Goal];: Derive more informative features from raw inputs

- #text(fill: black, weight: "bold")[Methods]

  - Combining variables (e.g., area = height × width)
  - Extracting parts (e.g., year from a date)
  - Logical features
    - E.g., transform #text(fill: blue)[2023-04-15] $arrow.r$
      (#text(fill: blue)[Saturday],
      #text(fill: blue)[is_weekend = True])

- #text(fill: black, weight: "bold")[Why it helps]

  - Encodes domain knowledge
  - Improves model expressiveness and performance

==== Dimensionality Reduction
<dimensionality-reduction>
- #text(fill: black, weight: "bold")[Goal];: Reduce number of features while preserving key
  information

- #text(fill: black, weight: "bold")[Why it helps]

  - Reduce overfitting
  - Reduce data redundancy
  - Improve model speed
  - Allow visualization

- #text(fill: black, weight: "bold")[Common techniques]

  - PCA: linear combinations that maximize variance
  - LDA: projects data to maximize class separability

- #text(fill: black, weight: "bold")[Example]

  - Reduce 1024x640 image pixels to 10 principal components
  - Quantize color images into gray scale

==== Discretization
<discretization>
- #text(fill: black, weight: "bold")[Goal];: Convert continuous values into categorical bins

- #text(fill: black, weight: "bold")[Why it helps]

  - Simplifies models or enables categorical algorithms
  - Helps detect threshold effects in data

- #text(fill: black, weight: "bold")[Techniques]

  - Equal-width binning
  - Quantile binning

- #text(fill: black, weight: "bold")[Example]

  - Discretize age
    - #text(fill: blue)[Child]: $\[ 0 \, 13 \)$
    - #text(fill: blue)[Teen]: $\[ 13 \, 20 \)$
    - #text(fill: blue)[Adult]: $\[ 20 \, 65 \)$
    - #text(fill: blue)[Senior]: $\[ 65 \, oo \)$
  - Age 32 $arrow.r$ #text(fill: blue)[Adult]

==== Noise Removal
<noise-removal>
- #text(fill: black, weight: "bold")[Goal];: Remove irrelevant or corrupt data variations

- #text(fill: black, weight: "bold")[Why it helps]

  - Improves signal clarity and model robustness
    - E.g., clean noisy speech by removing high-frequency noise

- #text(fill: black, weight: "bold")[Methods]

  - Smoothing (e.g., moving average)
  - Filtering (e.g., low-pass filter in audio)
