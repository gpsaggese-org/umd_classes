// Styled table with zebra striping, lateral lines, and configurable width.
#let styled-table(headers: (), rows: (), caption: none, col-widths: none, bold-first-col: true, size: 0.8em, width: 80%) = {
  let n = headers.len()
  let widths = if col-widths != none { col-widths } else { (1fr,) * n }

  // Zebra striping: alternate white and darker gray backgrounds on full rows
  let processed-rows = rows.enumerate().map(((idx, row)) => {
    let bg-color = if calc.rem(idx, 2) == 0 { white } else { rgb("#e8e8e8") }
    if bold-first-col {
      (
        table.cell(fill: bg-color, text(fill: black, weight: "bold", row.at(0))),
        ..row.slice(1).map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
      )
    } else {
      row.map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
    }
  })

  text(size: size,
    figure(
      align(center,
        block(width: width,
          table(
            columns: widths,
            align: (left,) * n,
            stroke: none,
            table.vline(x: 0, stroke: 2pt),
            table.hline(stroke: 2pt),
            table.header(
              ..headers.map(h => table.cell(fill: black, text(fill: white, weight: "bold", h)))
            ),
            table.hline(stroke: 1.5pt),
            ..processed-rows.flatten(),
            table.hline(stroke: 2pt),
            table.vline(x: n, stroke: 2pt),
          )
        )
      ),
      kind: table,
      caption: caption,
    )
  )
}

==== The Beginning (1943-1956)
<the-beginning-1943-1956>
- #text(fill: black, weight: "bold")[Artificial neuron]
  - Model (McCullock-Pitts 1943) based on:
    - Brain physiology
    - Propositional logic
  - Compute any function with connected neurons
    - Neuron on/off based on stimulation from neighboring neurons
    - Implement logical AND, OR, NOT with simple neuron networks
- #text(fill: black, weight: "bold")[Alan Turing, 1947]
  - Turing test, machine learning, reinforcement learning
  - Create human-level AI
    - Develop learning algorithms
    - Teach machine like a child
- #text(fill: black, weight: "bold")[Birth of AI]
  - McCarthy organized first AI workshop (1956)
  - The Logic Theorist (Newell and Simon, 1956)
    - Programs to "think non-numerically" and prove theorems

==== First AI winter (1975-1980)
<first-ai-winter-1975-1980>
- #text(fill: black, weight: "bold")[Early successes] of AI set high expectations

- In 1965-1975 AI didn't succeed on #text(fill: black, weight: "bold")[real problems] due to:

  - Solutions were based on human problem-solving methods
  - Difficulty handling "combinatorial explosion"
    - Theorem proving handles small problems with brute force, but
      doesn't scale
  - Neural networks needed:
    - Algorithms (e.g., backpropagation)
    - Compute power
    - Data

- #text(fill: black, weight: "bold")[First AI winter]

  - Research funding and enthusiasm dropped significantly
  - Slow AI progress through late 1970s

==== Expert Systems (1980-1990)
<expert-systems-1980-1990>
- #text(fill: black, weight: "bold")[Expert systems]
  - Aka "knowledge-based systems"
  - Combine weak methods with extensive domain knowledge as rules
  - Use inference engines to apply rules to facts
  - E.g., rule-based systems, logic programming (e.g., Prolog)
- #text(fill: black, weight: "bold")[Weak AI]
  - Aka narrow AI
  - Performs specific tasks, not general reasoning
  - Operates in a limited, well-defined domain
  - Uses "weak methods" (search, logic) that struggle to scale
- #text(fill: black, weight: "bold")[Commercial adoption and industry growth]
  - AI shifted to practical applications
  - Major US corporations deployed expert systems
  - AI emerged as a commercial industry

==== Second AI Winter (late 1980-early 1990)
<second-ai-winter-late-1980-early-1990>
- #text(fill: black, weight: "bold")[Hype in expert systems] didn't deliver

- #text(fill: black, weight: "bold")[Reasons]

  - Building/maintaining expert systems is difficult
  - Reasoning methods ignore uncertainty
  - Systems can't learn from experience
  - E.g., expert systems in medical diagnosis struggle with complex,
    variable patient data
  - E.g., early AI chess systems couldn't adapt to new strategies
    without manual updates

- #text(fill: black, weight: "bold")[Second AI winter] in late 1980-early 1990

==== Return of Neural Networks (1986-)
<return-of-neural-networks-1986->
- Back-propagation algorithm is (re)discovered (mid-1980s)
  - Developed in early 1960s
- #text(fill: black, weight: "bold")[Two approaches to AI are back]
  - Connectionist paradigm
    - Neural networks
    - E.g., recognizing handwritten digits
  - Symbolic paradigm
    - E.g., solving logical puzzles with rules
- #text(fill: black, weight: "bold")[Why connectionist approach?]
  - Concepts not well-defined using symbolic axioms
    - Forms fluid internal concepts
    - Represents real-world complexity better
  - Neural networks can learn from examples, e.g.,
    - Image recognition: identify objects by learning from labeled
      images

<progress-in-speech-recognition>

==== Reinforcement Learning
<reinforcement-learning>
- #text(fill: black, weight: "bold")[Reinforcement learning]

==== Solutions to Problem of Control

  - Governments and international organizations established advisory

==== Cooperative Inverse Reinforcement Learning
<cooperative-inverse-reinforcement-learning>
- AI infers human goals based on actions

- #text(fill: black, weight: "bold")[Observation];: GP looks tired, sits on the couch, observes the
  messy table, and starts watching TV

- #text(fill: black, weight: "bold")[Inference];: AI infers:

  - GP is tired and wants to relax
  - Messy coffee table bothers him

- #text(fill: black, weight: "bold")[Action];: AI:

  - Fetches a glass of water
  - Tidies up the coffee table without disturbing GP

- #text(fill: black, weight: "bold")[Feedback loop];: AI monitors GP's reactions

  - If GP is relaxed and happy, AI understanding is reinforced
  - If GP is not happy, AI adjusts actions and improves inference
