// Styled table with zebra striping, lateral lines, and configurable width.
#let styled-table(headers: (), rows: (), caption: none, col-widths: none, bold-first-col: true, size: 0.8em, width: 80%) = {
  let n = headers.len()
  let widths = if col-widths != none { col-widths } else { (1fr,) * n }

  // Zebra striping: alternate white and darker gray backgrounds on full rows
  let processed-rows = rows.enumerate().map(((idx, row)) => {
    let bg-color = if calc.rem(idx, 2) == 0 { white } else { rgb("#e8e8e8") }
    if bold-first-col {
      (
        table.cell(fill: bg-color, text(fill: black, weight: "bold", row.at(0))),
        ..row.slice(1).map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
      )
    } else {
      row.map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
    }
  })

  text(size: size,
    figure(
      align(center,
        block(width: width,
          table(
            columns: widths,
            align: (left,) * n,
            stroke: none,
            table.vline(x: 0, stroke: 2pt),
            table.hline(stroke: 2pt),
            table.header(
              ..headers.map(h => table.cell(fill: black, text(fill: white, weight: "bold", h)))
            ),
            table.hline(stroke: 1.5pt),
            ..processed-rows.flatten(),
            table.hline(stroke: 2pt),
            table.vline(x: n, stroke: 2pt),
          )
        )
      ),
      kind: table,
      caption: caption,
    )
  )
}

==== AI and Mathematics
<ai-and-mathematics>
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[What are the formal rules to draw valid conclusions?]]
  - #text(fill: black, weight: "bold")[Formal logic]
    - Logical deduction rules (Boole, 1850)
    - First-order logic includes objects and relations (Frege, 1879)
  - #text(fill: black, weight: "bold")[Limits to deduction]
    - Some statements are "undecidable"
    - Incompleteness theorem: in any formal theory true statements exist
      that cannot be proved (Godel, 1931)
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[How do we reason with uncertain information?]]
  - #text(fill: black, weight: "bold")[Probability]
    - Mathematics of uncertainty
    - Cardano, Pascal, Bernoulli, Bayes (1500-1700)
  - #text(fill: black, weight: "bold")[Statistics]
    - Combines data with probability
    - E.g., experiment design, data analysis, hypothesis testing,
      asymptotics

==== AI and Economics (1/2)
<ai-and-economics-12>
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[How to make decisions to maximize payoff given preferences?]]
  - #text(fill: black, weight: "bold")[Economies]
    - Agents maximize economic well-being (utility)
    - Studies desires and preferences
  - #text(fill: black, weight: "bold")[Decision theory]
    - Making decisions under uncertainty for preferred outcomes
    - Probability theory + utility theory
    - E.g., investment choices, policy decisions
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[How to make decisions when payoffs are result of several actions?]]
  - #text(fill: black, weight: "bold")[Operations research]
    - Make rational decisions with payoffs for sequence of actions
      (Bellman, 1957)
    - E.g., Markov Decision Processes
  - #text(fill: black, weight: "bold")[Satisficing]
    - Decisions that are good enough
    - Closer to human behavior
    - E.g., choosing a restaurant that meets basic criteria rather than
      finding the perfect one

==== AI and Economics (2/2)
<ai-and-economics-22>
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[How multiple agents with different goals act?]]
  - #text(fill: black, weight: "bold")[Large economies]
    - Many agents with no mutual impact
    - Ignore other agents' actions
    - E.g., national economy where individual actions don't affect
      market
  - #text(fill: black, weight: "bold")[Small economies]
    - One player's actions influence others' utility
    - E.g., local market where one seller's pricing affects competitors
  - #text(fill: black, weight: "bold")[Game theory]
    - Small economies resemble a "game" (Von Neumann, 1944)
    - Rational agents might need randomized strategies
    - E.g., rock-paper-scissors where randomization prevents
      predictability

==== AI and Computer Science
<ai-and-computer-science>
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[What can be computed?]]
  - #text(fill: black, weight: "bold")[Algorithm]
    - Procedure to solve problems
    - E.g., algorithm for computing GCD (Euclid, 300 BCE)
  - #text(fill: black, weight: "bold")[Limits to computation]
    - Turing machine (1936): computes any computable function
    - Some functions are non-computable
    - E.g., the halting problem, i.e., decide if a program terminates
  - #text(fill: black, weight: "bold")[Tractability]
    - Complexity classes: polynomial vs exponential complexity
    - Problem is intractable if solving time grows exponentially with
      size
    - P vs NP

==== AI and Control Theory
<ai-and-control-theory>
- #text(fill: black, weight: "bold")[#text(fill: black, weight: "bold")[How can artifacts operate under their own control?]]
  - #text(fill: black, weight: "bold")[Control theory]
    - Study self-regulating feedback control systems
    - E.g., a water regulator that maintains a constant water flow
    - Mechanisms to minimize error between current and goal states
    - Kalman Filter (Kalman, 1960)
    - Based on calculus, matrix, stochastic optimal control
    - AI: logical inference, symbolic planning, computation
