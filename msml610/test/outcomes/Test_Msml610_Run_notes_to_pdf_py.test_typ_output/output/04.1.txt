==== Naive Bayes Model
<naive-bayes-model>
- #text(fill: black, weight: "bold")[Problem];: predict classes $H_1 \, . . . \, H_n$ using
  evidence $bold(underline(E))$:
  - Use Bayes' rule of conditional probability to decide output class
    $H_1 \, . . . H_n$ given evidence $bold(underline(E))$:
    $ Pr \( H_j \| bold(underline(E)) \) = frac(Pr \( bold(underline(E)) \| H_j \) Pr \( H_j \), Pr \( bold(underline(E)) \)) $
    where $bold(underline(E))$ is the vector of features
  - Training data estimates joint probability
    $Pr \( H_i \, bold(underline(E)) \)$
- #text(fill: black, weight: "bold")[Assumptions:]
  + Features are independent
  + Features are equally important (or at least all relevant)
- #text(fill: black, weight: "bold")[Naive Bayes model:]
  - Called "naive" due to the simplifying assumption of independence,
    even if not true
  - Works surprisingly well

  $ Pr \( H_j \| bold(underline(E)) \) = frac(Pr \( bold(underline(E)) \| H_j \) Pr \( H_j \), Pr \( bold(underline(E)) \)) $
  where:
  - $H_j$: event to predict
    - E.g., #text(fill: blue)[play = yes]
  - $bold(underline(E))$: event with feature values

      #text(fill: blue)[outlook=sunny, temperature=high, humidity=high, windy=yes]

==== Naive Bayes: Weather Prediction Example
<naive-bayes-weather-prediction-example-2>
- The #text(fill: black, weight: "bold")[model] is:
  $ Pr \( H_j \| bold(underline(E)) \) = frac(Pr \( bold(underline(E)) \| H_j \) Pr \( H_j \), Pr \( bold(underline(E)) \)) $
  where:
  - $Pr \( H_j \)$: #text(fill: black, weight: "bold")[prior probability] (probability of the
    outcome before evidence $bold(underline(E))$)
    - E.g., $Pr \( upright("play = yes") \)$
    - Computed from training set as:
      $Pr \( H_j \) = sum_(k = 1)^N Pr \( H_j and bold(underline(E))_k \)$
  - $Pr \( bold(underline(E)) \)$: #text(fill: black, weight: "bold")[probability of the evidence]
    - Computed from training set
    - Not needed as it is common to the probability of each class
  - $Pr \( bold(underline(E)) \| H_j \)$: #text(fill: black, weight: "bold")[conditional
    probability]
    - Computed as independent probabilities (the "naive" assumption):
- #text(fill: black, weight: "bold")[Interpretation of Bayes theorem]
  - The prior is modulated through the conditional probability and the
    probability of the evidence

==== Naive Bayes: Why Independence Assumption
<naive-bayes-why-independence-assumption>
- #text(fill: black, weight: "bold")[Independence assumption] factors joint probability into
  marginal probabilities:

- #text(fill: black, weight: "bold")[Pros];:

  - Simplifies probability computation
  - Aids generalization due to few samples needed

- #text(fill: black, weight: "bold")[Cons];:

  - Assumption may not be true

==== Estimating Probabilities: MLE
<estimating-probabilities-mle>
- #text(fill: black, weight: "bold")[Maximum Likelihood Estimate] (MLE) estimates event probability
  by counting occurrences among all possible events:
  $ Pr \( bold(underline(E)) = bold(underline(e))' \) = frac(\# I \( bold(underline(E)) = bold(underline(e))' \), K) $

- For Naive Bayes, we need to estimate probability of each feature:
  $ Pr \( E_i = e' \) = frac(\# I \( E_i = e' \), sum_(j = 1)^V \# I \( E_i = e_k \)) $

- #text(fill: black, weight: "bold")[Problem]
  - Value $e'$ of feature $E_i$ not in training set with output class
    $H_j$
  - Estimated probability $Pr \( E_i = e' \| H_j \) = 0$
  - Plugging $Pr \( E_i = e' \| H_j \) = 0$ into
    $ Pr \( H_j \| bold(underline(E)) \) approx Pr \( E_1 = e_1 \| H_j \) dot.op . . . dot.op Pr \( E_n = e_n \| H_j \) $
  - Yields $Pr \( H_j \| bold(underline(E)) \) = 0$
    $arrow.r.double.long$ impossible to decide output

==== Estimating Probabilities: Laplace Estimator
<estimating-probabilities-laplace-estimator>
- Use Laplace estimator for events not in training set instead of MLE

- #text(fill: black, weight: "bold")[Maximum likelihood estimate] (MLE)
  $ Pr \( E_i = e' \) = frac(\# I \( E_i = e' \), sum_(j = 1)^V \# I \( E_i = e_k \)) $

- #text(fill: black, weight: "bold")[Laplace estimator]

  - Adds 1 to each count and $V$ (number of feature values) to
    denominator:
    $ Pr \( E_i = e' \) = frac(1 + \# I \( E_i = e' \), sum_(j = 1)^V \( 1 + \# I \( E_i = e' \) \)) = frac(1 + \# I \( E_i = e' \), V + sum_(j = 1)^V \# I \( E_i = e' \)) $
  - Blends prior of equiprobable feature values with MLE estimates

==== Decision Trees: Pros
<decision-trees-pros>
- Works for both #text(fill: black, weight: "bold")[regression and classification]

- #text(fill: black, weight: "bold")[Simple to understand and interpret]

  - White box model: explainable decisions
  - Visualizable
  - Can be created by hand

- Requires #text(fill: black, weight: "bold")[little data preparation]

  - Invariant under feature scaling
    - No data normalization
    - No dummy variables
  - Handles numerical and categorical data
  - Robust to irrelevant features (implicit feature selection)
  - Missing values are treated:
    - As their own value; or
    - Assigned the most frequent value (i.e., imputation)

- #text(fill: black, weight: "bold")[Scalable]

  - Performs well with large datasets

==== Decision Trees: Cons
<decision-trees-cons>
- #text(fill: black, weight: "bold")[Learning optimal decision tree] is NP-complete
  - Much worse than complexity of OLS
  - Algorithms use heuristics (e.g., greedy algorithms)
- #text(fill: black, weight: "bold")[Risk of overfitting]
  - Solutions:
    - Pruning
    - Minimum samples at a leaf node
    - Max depth of trees

==== Splitting at One Node: Problem Formulation
<splitting-at-one-node-problem-formulation>
- #text(fill: black, weight: "bold")[Consider the $m$-th node] of a decision tree
  - Given $p_i = \( bold(underline(x))_i \, y_i \)$ where
    $i = 1 \, . . . \, N_m$, with training vectors
    $bold(underline(x))_i$ and labels $y_i$
  - Candidate splits are $theta = \( j \, t_m \)$ with feature $j$ and
    threshold $t_m$
  - Each split partitions data into subsets:
  - Impurity of a split is defined as:
    $ H \( j \, t_m \) = n_L / N_m H \( Q_L \) + n_R / N_m H \( Q_R \) $
  - Find split $\( j \, t_m \)^(\*)$ minimizing $H \( j \, t_m \)$
- #text(fill: black, weight: "bold")[Recurse] on $Q_L \( j \, t_m \)^(\*)$ and
  $Q_R \( j \, t_m \)^(\*)$

==== Probability of Classification in a Node
<probability-of-classification-in-a-node>
- Assume $m$-th node has $N_m$ objects $x_i$ in $K$ classes

- Compute class probability in $m$-th node as:
  $ hat(f)_(m \, k) eq.delta Pr \( upright("pick object of class ") k upright(" in ") m upright("-th node ") \) = 1 / N_m sum_(x_i in upright(" node ")) I \( c \( x_i \) = k \) $
  where $y_i = c \( x_i \)$ is the correct class for element $x_i$

- E.g., if there are $N_m = 10$ objects belonging to $K = 3$ classes

  - 3 red, 6 blue, 1 green
  - The probability of classification $hat(f)_(m \, k)$ are:
    - Red = 3/10
    - Blue = 6/10
    - Green = 1/10

==== Misclassification Error: Definition
<misclassification-error-definition>
- You have several class probabilities $p_i$ and need a single
  probability

  - Consider worst case: most common class $k'$ in node

- #text(fill: black, weight: "bold")[Misclassification error]
  $ H_M \( p \) eq.delta 1 - sans("max")_k p_k $

- #text(fill: black, weight: "bold")[Binary classifier]

  - Best case (perfect purity)
    - Only one class in node
    - $H_M \( p \) = 0$
  - Worst case (perfect impurity)
    - 50-50 split between classes in node
    - $H_M \( p \) = 0.5$

- #text(fill: black, weight: "bold")[Multi-class classifier] with $K$ classes

  - Misclassification error has upper bound: $1 \/ K$

==== Gini Impurity Index: Definition
<gini-impurity-index-definition>
- #text(fill: black, weight: "bold")[Gini index] $H_G \( p \)$ is probability of picking an element
  randomly and classifying it incorrectly
  - By using the law of total probability:
- #text(fill: black, weight: "bold")[Binary classifier]
  - $H_G \( p \)$ is between 0 (perfect purity) and 0.5 (perfect
    impurity)
- #text(fill: black, weight: "bold")[Multi-class classifier] with $K$ classes
  - $H_G \( p \)$ has upper bound: $1 - K 1 / K^2 = 1 - 1 / K$

==== Information Gain: Definition
<information-gain-definition>
- Aka cross-entropy (remember entropy is $- p log p$)

- #text(fill: black, weight: "bold")[Information gain]
  $ H_(I G) = - sum_(k = 1)^K p_k dot.op log_2 \( p_k \) $

- #text(fill: black, weight: "bold")[Binary classifier]

  - $H_(I G)$ varies between 0 (perfect purity) and 1 (perfect impurity)

- #text(fill: black, weight: "bold")[Multi-class classifier] with $K$ classes

  - $H_(I G)$ has upper bound: $log K$

==== Measures of Impurity: Examples
<measures-of-impurity-examples>
- Consider the case of 16 elements in a node , belonging to 2 classes

- If all elements are of the same class:

  - Misclassification error $= 0$
  - Gini index $= 1 - \( 1 - 0 \) = 0$
  - Information gain
    $= - \( 1 dot.op log_2 \( 1 \) - 0 dot.op log_2 \( 0 \) \) = 0$

- If one element is of one class:

  - Misclassification error =
    $1 - sans("max") \( 1 / 16 \, 1 / 15 \) = 1 / 16$
  - Gini index $= 1 - \( \( 1 / 16 \)^2 + \( 1 / 15 \)^2 \) = 0.12$
  - Information gain
    $= - \( 1 / 16 log_2 \( 1 / 16 \) + 15 / 16 log_2 \( 15 / 16 \) \) = 0.34$

- If elements are split in the two classes equally:

  - Misclassification error $= 8 / 16 = 0.5$
  - Gini index $= 1 - \( 8 / 16^2 + 8 / 16^2 \) = 0.5$
  - Information gain
    $= - \( 8 / 16 log_2 \( 8 / 16 \) + 8 / 16 log_2 \( 8 / 16 \) \) = 1$

==== Measures of Impurity for Regression
<measures-of-impurity-for-regression>
- For continuous variables with $N_m$ observations at a node, minimize
  mean squared error:

  $  & c_m = 1 / N_m sum_(i in N_m) y_i & upright(" (average class)")\
   & H = 1 / N_m sum_(i in N_m) \( y_i - c_m \)^2 & upright(" (variance)")\
   $

==== Tips for Using Trees
<tips-for-using-trees>
- #text(fill: black, weight: "bold")[Decision trees overfit] with #text(fill: black, weight: "bold")[many features]
  - Get right ratio of training samples to features
- #text(fill: black, weight: "bold")[Solutions]
  - Use dimensionality reduction (PCA, feature selection) to remove
    non-discriminative features

  - Use maximum tree depth to prevent overfitting

  - Control minimum number of examples at a leaf node / split

    - Small number $arrow.r$ overfitting
    - Large number $arrow.r$ no learning
- #text(fill: black, weight: "bold")[Balance dataset before training] to avoid #text(fill: black, weight: "bold")[bias]
  - Normalize sum of sample weights for each class

==== Feature Selection with Trees
<feature-selection-with-trees>
- #text(fill: black, weight: "bold")[Intuition]
  - Top tree features predict more samples
- #text(fill: black, weight: "bold")[Importance of a variable]
  - Feature's control over samples estimates importance
  - Feature's depth as a decision node assesses importance
- #text(fill: black, weight: "bold")[Trees are unstable]
  - Reduce estimation variance by averaging variable depth over multiple
    randomized trees (random forest)

==== Embeddings with Trees
<embeddings-with-trees>

  - Learning a tree is like a non-parametric density estimation
  - Neighboring data points likely lie within the same leaf
- #text(fill: black, weight: "bold")[Embedding: unsupervised data transformation]
  - Tree encodes data by indices of leaves a data point belongs to
  - Index encoded one-hot for high-dimensional, sparse, binary coding
- Use #text(fill: black, weight: "bold")[number of trees and max depth per tree] to control space
  size

==== From Decision Trees to Random Forests
<from-decision-trees-to-random-forests>
- Decision trees are #text(fill: black, weight: "bold")[high capacity models];:

  - Low bias
  - High variance

- Idea: apply ensemble methods to trees $arrow.r$ "random forests"

- #text(fill: black, weight: "bold")[Bagging]

  - Reduces variance in "unstable" non-linear models
    - Learning trees is unstable
  - Best with complex models (e.g., fully grown trees)
    - Boosting works best with weak models (e.g., shallow decision
      trees, aka tree stumps)
  - Works for regression and classification
  - Customizable for trees
    - Different types of randomization in trees

- #text(fill: black, weight: "bold")[Bias-variance trade-off] in random forests

  - Forest bias could increase compared to a single non-random tree
  - Forest variance reduced by averaging, usually compensating for bias
    increase

==== Randomization in Trees
<randomization-in-trees>
- #text(fill: black, weight: "bold")[Bagging] (bootstrap aggregate) / perturb-and-combine
  techniques designed for trees
  + Training samples (with replacement)
  + Picking features (random subspaces)
  + Decision split thresholds
  + All the above
- #text(fill: black, weight: "bold")[Random forests]
  - Each tree built from samples drawn with replacement (bootstrap
    sample)
  - Split picked as best among random subset of features
- #text(fill: black, weight: "bold")[Extremely randomized trees] (aka "Extra-Trees")
  - Thresholds randomized
  - More randomness than random forests
  - Trade off more bias for variance
- #text(fill: black, weight: "bold")[Combine random forests]
  - Majority vote on class
  - Averaging prediction probability
  - Averaging prediction

==== Linear Regression Model
<linear-regression-model>
- #text(fill: black, weight: "bold")[Data set]

  - $\( bold(underline(x))_1 \, y_1 \) \, . . . \, \( bold(underline(x))_N \, y_N \)$
  - $N$ examples
  - $P$ features, $bold(underline(x))_i in bb(R)^P$

- #text(fill: black, weight: "bold")[Linear regression model]
  $ h \( bold(underline(x)) \) = sum_(i = 1)^P w_i x_i = bold(underline(w))^T bold(underline(x)) in bb(R) $

- Add #text(fill: black, weight: "bold")[bias term] $w_0$ to model with $x_0 = 1$ to data
  $ h \( bold(underline(x)) \) = w_0 + sum_(i = 1)^P w_i x_i = sum_(i = 0)^P w_i x_i = bold(underline(w))^T bold(underline(x)) $

==== Linear Regression: In-sample Error
<linear-regression-in-sample-error>
- For regression, use #text(fill: black, weight: "bold")[squared error for in-sample error];:
  $ E_(i n) \( h \) = 1 / N sum_(i = 1)^N \( h \( bold(underline(x))_i \) - f \( bold(underline(x))_i \) \)^2 $

- Squared error for #text(fill: black, weight: "bold")[linear regression]
  $ E_(i n) \( h \) = E_(i n) \( bold(underline(w)) \) = 1 / N sum_(i = 1)^N \( bold(underline(w))^T bold(underline(x))_i - y_i \)^2 $

- Squared error #text(fill: black, weight: "bold")[in vector form]
  $ E_(i n) \( h \) = 1 / N parallel bold(underline(underline(X))) bold(underline(w)) - bold(underline(y)) parallel^2 = 1 / N \( bold(underline(underline(X))) bold(underline(w)) - bold(underline(y)) \)^T \( bold(underline(underline(X))) bold(underline(w)) - bold(underline(y)) \) $
  where:

  - $bold(underline(underline(X)))$ is the matrix with examples
    $bold(underline(x))_i^T$ as rows ("design matrix")
  - $bold(underline(underline(X)))$ is a tall matrix with few parameters
    ($P$) and many examples ($N$)
  - $bold(underline(y))$ is the column vector with all outputs (target
    vector)

==== Linear Regression: Find Optimal Model
<linear-regression-find-optimal-model>
- You want to minimize
  $E_(i n) \( bold(underline(w)) \) = \( bold(underline(underline(X))) bold(underline(w)) - bold(underline(y)) \)^T \( bold(underline(underline(X))) bold(underline(w)) - bold(underline(y)) \)$
  with respect to $bold(underline(w))$

- If the square matrix
  $bold(underline(underline(X)))^T bold(underline(underline(X)))$ is
  invertible:
  $ bold(underline(w))^(\*) = \( bold(underline(underline(X)))^T bold(underline(underline(X))) \)^(- 1) bold(underline(underline(X)))^T bold(underline(y)) = bold(underline(underline(X)))^dagger bold(underline(y)) $

- The matrix
  $bold(underline(underline(X)))^dagger eq.delta \( bold(underline(underline(X)))^T bold(underline(underline(X))) \)^(- 1) bold(underline(underline(X)))^T$
  is called #text(fill: black, weight: "bold")[pseudo-inverse]

  - It generalizes the inverse for non-square matrices, in fact:
    - $bold(underline(underline(X)))^dagger bold(underline(underline(X))) = bold(underline(underline(I)))$
    - If $bold(underline(underline(X)))$ is square and invertible, then
      $bold(underline(underline(X)))^dagger = bold(underline(underline(X)))^(- 1)$

==== Complexity of One-Step Learning
<complexity-of-one-step-learning>
- Learning with the pseudo-inverse is #text(fill: black, weight: "bold")[one-step learning]
  - Contrasts with iterative methods, e.g., gradient descent
- Inverting a square matrix of size $P$ is related to the number of
  parameters, not examples $N$
  - Complexity of one-step learning is $O \( P^3 \)$

==== Linear Models Are Linear in What?
<linear-models-are-linear-in-what>
- A #text(fill: black, weight: "bold")[model is linear] when the signal
  $s = sum_(i = 0)^P w_i x_i = bold(underline(w))^T bold(underline(x))$
  is linear #text(fill: black, weight: "bold")[with variables]
  - Unknown variables: weights $w_i$
  - Inputs $x_i$ are fixed
- Applying a #text(fill: black, weight: "bold")[non-linear transform to inputs]
  $z_i = Phi \( x_i \)$ keeps the model linear, e.g.,
  - Positive/negative part (e.g.,
    $z_i = R E L U \( x_i \) \, R E L U \( - x_i \)$)
  - Waterfall (conditioning model to different feature ranges)
  - Thresholding (e.g., $z_i = sans("min") \( x_i \, T \)$)
  - Indicator variables (e.g., $z_i = I \( x_i > 0 \)$)
  - Winsorizing (replace outliers with a large constant value)
- Applying a #text(fill: black, weight: "bold")[non-linear transform to weights]
  $z_i = Phi \( w_i \)$ makes the model non-linear

==== Non-Linear Transformations in Linear Models
<non-linear-transformations-in-linear-models>
- #text(fill: black, weight: "bold")[Transform variables]
  - Use $Phi : cal(X) arrow.r cal(Z)$
  - Transform each point $bold(underline(x))_n in cal(X) = bb(R)^d$ into
    a point in feature space
    $bold(underline(z))_n = Phi \( bold(underline(x))_n \) in cal(Z) = bb(R)^(tilde(d))$
    with $d eq.not tilde(d)$
- #text(fill: black, weight: "bold")[Learn]
  - Learn linear model in $cal(Z)$, obtaining
    $bold(underline(tilde(w)))$ for separating hyperplane
- #text(fill: black, weight: "bold")[Predict]
  - Evaluate model on new point in $cal(Z)$:
    $ y = sans("sign") \( bold(underline(tilde(w)))^T Phi \( bold(underline(x)) \) \) upright("or") quad y = bold(underline(tilde(w)))^T Phi \( bold(underline(x)) \) $
- Compute #text(fill: black, weight: "bold")[decision boundary]
  - In $cal(X)$ if $Phi$ is invertible; or
  - By classifying any $bold(underline(x)) in cal(X)$ in $cal(Z)$

==== Linear Regression for Classification
<linear-regression-for-classification>
- Use #text(fill: black, weight: "bold")[linear regression for classification]
  - Transform outputs into ${ + 1 \, - 1 } in bb(R)$
  - Learn
    $bold(underline(w))^T bold(underline(x))_n approx y_n = plus.minus 1$
  - Use $sans("sign") \( bold(underline(w))^T bold(underline(x))_n \)$
    as model (perceptron)
- #text(fill: black, weight: "bold")[Not optimal];: outliers influence fit due to square distance
  metric
  - Use weights from linear regression to initialize a learning
    algorithm for classification (e.g., PLA)

==== Perceptron Learning Algorithm (PLA)
<perceptron-learning-algorithm-pla>
- First machine learning algorithm discovered

- #text(fill: black, weight: "bold")[Algorithm]

  - Training set
    $cal(D) = { \( bold(underline(x))_1 \, y_1 \) \, . . . \, \( bold(underline(x))_n \, y_n \) }$
  - Initialize weights $bold(underline(w))$
    - Random values
    - Use linear regression for classification as seed
  - Pick a misclassified point
    $sans("sign") \( bold(underline(w))^T bold(underline(x))_i \) eq.not y_i$
    from training set $cal(D)$
  - Update weights:
    $bold(underline(w)) \( t + 1 \) = bold(underline(w)) \( t \) + y_i bold(underline(x))_i$
    - Like stochastic gradient descent
  - Iterate until no misclassified points

- Algorithm #text(fill: black, weight: "bold")[converges] (slowly) for linearly separable data

- #text(fill: black, weight: "bold")[Pocket version of PLA]

  - Idea
    - Continuously update solution
    - Keep best solution "in the back pocket"
  - Have a solution if stopping after max iterations
