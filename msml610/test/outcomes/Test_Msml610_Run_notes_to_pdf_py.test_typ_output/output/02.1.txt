// Styled table with zebra striping, lateral lines, and configurable width.
#let styled-table(headers: (), rows: (), caption: none, col-widths: none, bold-first-col: true, size: 0.8em, width: 80%) = {
  let n = headers.len()
  let widths = if col-widths != none { col-widths } else { (1fr,) * n }

  // Zebra striping: alternate white and darker gray backgrounds on full rows
  let processed-rows = rows.enumerate().map(((idx, row)) => {
    let bg-color = if calc.rem(idx, 2) == 0 { white } else { rgb("#e8e8e8") }
    if bold-first-col {
      (
        table.cell(fill: bg-color, text(fill: black, weight: "bold", row.at(0))),
        ..row.slice(1).map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
      )
    } else {
      row.map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
    }
  })

  text(size: size,
    figure(
      align(center,
        block(width: width,
          table(
            columns: widths,
            align: (left,) * n,
            stroke: none,
            table.vline(x: 0, stroke: 2pt),
            table.hline(stroke: 2pt),
            table.header(
              ..headers.map(h => table.cell(fill: black, text(fill: white, weight: "bold", h)))
            ),
            table.hline(stroke: 1.5pt),
            ..processed-rows.flatten(),
            table.hline(stroke: 2pt),
            table.vline(x: n, stroke: 2pt),
          )
        )
      ),
      kind: table,
      caption: caption,
    )
  )
}

==== Machine Learning Paradigms
<machine-learning-paradigms>
- How do you set up the learning problem?

  - #text(fill: black, weight: "bold")[Supervised learning]
    - The dataset includes inputs with corresponding outputs
    - Develop an input-output relationship
  - #text(fill: black, weight: "bold")[Unsupervised learning]
    - The data is unlabeled, discover structure within the data
    - E.g., anomaly detection, clustering
  - #text(fill: black, weight: "bold")[Reinforcement learning]
    - The correct answer is not immediately available
    - Evaluate actions based on final outcomes
  - #text(fill: black, weight: "bold")[Active learning]
    - Not all examples are available initially
    - Request outputs for specific inputs
  - …

==== Machine Learning Theory
<machine-learning-theory>
- #text(fill: black, weight: "bold")[VC theory]
  - Measure model capacity and generalize based on hypothesis space
    complexity
- #text(fill: black, weight: "bold")[Bias-variance decomposition]
  - Prediction error is the sum of:
    - Bias: Error from simplistic model assumptions
    - Variance: Error due to sensitivity to training data fluctuations
- #text(fill: black, weight: "bold")[Computation complexity]
  - Related to information theory and compression
  - E.g., Minimum Description Length (MDL) measures model complexity via
    efficient model and data description
- #text(fill: black, weight: "bold")[Bayesian approach]
  - Treat ML as probability
  - Combine prior knowledge with observed data to update belief about a
    model
- #text(fill: black, weight: "bold")[Problem in ML theory]
  - Assumptions may not align with practical problems
