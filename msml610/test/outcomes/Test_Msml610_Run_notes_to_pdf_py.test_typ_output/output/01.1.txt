// Styled table with zebra striping, lateral lines, and configurable width.
#let styled-table(headers: (), rows: (), caption: none, col-widths: none, bold-first-col: true, size: 0.8em, width: 80%) = {
  let n = headers.len()
  let widths = if col-widths != none { col-widths } else { (1fr,) * n }

  // Zebra striping: alternate white and darker gray backgrounds on full rows
  let processed-rows = rows.enumerate().map(((idx, row)) => {
    let bg-color = if calc.rem(idx, 2) == 0 { white } else { rgb("#e8e8e8") }
    if bold-first-col {
      (
        table.cell(fill: bg-color, text(fill: black, weight: "bold", row.at(0))),
        ..row.slice(1).map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
      )
    } else {
      row.map(cell => table.cell(fill: bg-color, text(fill: rgb("#555555"), cell)))
    }
  })

  text(size: size,
    figure(
      align(center,
        block(width: width,
          table(
            columns: widths,
            align: (left,) * n,
            stroke: none,
            table.vline(x: 0, stroke: 2pt),
            table.hline(stroke: 2pt),
            table.header(
              ..headers.map(h => table.cell(fill: black, text(fill: white, weight: "bold", h)))
            ),
            table.hline(stroke: 1.5pt),
            ..processed-rows.flatten(),
            table.hline(stroke: 2pt),
            table.vline(x: n, stroke: 2pt),
          )
        )
      ),
      kind: table,
      caption: caption,
    )
  )
}

==== Human Intelligence
<human-intelligence>
- We call ourselves "homo sapiens" because intelligence sets us apart
  from animals

- For thousands of years, we tried to understand how we think

- One of the biggest mysteries

  - Brain is a small mass of matter
  - Our brain can understand nature secrets, e.g., theory of relativity,
    quantum mechanics, black holes in the universe
  - How can brain understand, predict, and manipulate a world more
    complicated than itself?

==== Artificial Intelligence
<artificial-intelligence>
- #text(fill: red, weight: "bold")[Definition]: The term
  #emph["Artificial Intelligence"] was coined in 1956

- #text(fill: green, weight: "bold")[Goal]

  - Understand human intelligence
  - Create intelligent entities
  - #emph["What I cannot create, I do not understand"] (Feynman, 1988)

- #text(fill: blue, weight: "bold")[Characteristics]

  - Universal and applicable to any human activity and task
  - Its impact is greater than any previous historical event
  - Currently generates trillions of dollars annually in revenue
  - Presents many unresolved problems
    - E.g., major concepts in physics might be established

==== AI Formal Definition
<ai-formal-definition>
- #text(fill: red, weight: "bold")[Definition]: AI is characterized
  along #text(fill: black, weight: "bold")[two key axes]

  - Thinking vs.~Acting
  - Human vs.~Rational (ideal performance)

- This yields four possible definitions of AI as a machine that can:

  + Think humanly
  + Think rationally
  + Act humanly
  + Act rationally

- #text(fill: black, weight: "bold")[Question];: Which definition best captures what AI should aim
  for?

- #text(fill: black, weight: "bold")[Key insight];: Building machines that #text(fill: black, weight: "bold")[act rationally]
  should be the ultimate goal of AI

==== 1. AI as Thinking Humanly
<ai-as-thinking-humanly>
- #text(fill: red, weight: "bold")[Problem]: To build machines that
  think like humans, we need to first #text(fill: black, weight: "bold")[determine how humans
  think]

- #text(fill: black, weight: "bold")[Pros]

  - Express precise theory of the human mind as a computer program

- #text(fill: black, weight: "bold")[Cons]

  - Unknown workings of the human mind
  - Anthropocentric definition

==== 2. AI as Thinking Rationally
<ai-as-thinking-rationally>
- #text(fill: red, weight: "bold")[Question]: What are the rules of
  #text(fill: black, weight: "bold")[correct thinking];?
  - Given correct premises, yield correct conclusions
- #text(fill: green, weight: "bold")[Approach]: #text(fill: black, weight: "bold")[Logic] studies
  the "laws of thought"
  - Formalize statements about objects and their relations
- #text(fill: blue, weight: "bold")[Technique]: #text(fill: black, weight: "bold")[Automatic
  theorem proving]
  - Programs solve problems in logical notation
  - Run indefinitely if no solution exists (related to the halting
    problem)

==== Thinking Rationally: Cons
<thinking-rationally-cons>
+ #text(fill: black, weight: "bold")[Formalizing informal knowledge is difficult]
  - #text(fill: red, weight: "bold")[Example]: #emph["A handshake occurs
    when two people extend, grip, shake hands, then release."]
  - Formal logic representation:
    $ exists x \, y thin \( upright("Person") \( x \) and upright("Person") \( y \) and x eq.not y and upright("Hand") \( x \, h_x \) and upright("Hand") \( y \, h_y \) and upright("MoveToward") \( h_x \, h_y \) and upright("Contact") \( h_x \, h_y \) and upright("Shake") \( h_x \, h_y \) and upright("Release") \( h_x \, h_y \) \) $
+ #text(fill: black, weight: "bold")[Probabilistic nature of knowledge]
  - #text(fill: blue, weight: "bold")[Example]: In medicine,
    #emph["Fever, cough, and fatigue could indicate flu, COVID-19, or
    another illness."]
+ #text(fill: black, weight: "bold")[Scalability challenges]
  - Large problems may need heuristics for practical solutions
+ #text(fill: black, weight: "bold")[Intelligence requires more than rational thinking]
  - Importance of agent interaction with the world
  - Problem of the "body"

==== Turing Test: Pros and Cons
<turing-test-pros-and-cons>
- #text(fill: black, weight: "bold")[Pros]
  - Operational definition of intelligence
  - Sidestep philosophical vagueness
    - What is consciousness?
    - Can a machine think?
- #text(fill: black, weight: "bold")[Cons]
  - Intelligence defined by #text(fill: black, weight: "bold")[anthropomorphic] criteria in human
    terms
    - Multiple forms of non-human intelligence exist
  - Intelligence by Turing test means #text(fill: black, weight: "bold")[fooling humans] into
    thinking it is human
  - #text(fill: red, weight: "bold")[Example]: Aeronautical engineering
    is about
    - Correct: Focus on wind tunnels and aerodynamics
    - Incorrect: Designing machines that imitate birds

==== 4. AI as Acting Rationally
<ai-as-acting-rationally>
- #text(fill: red, weight: "bold")[Definition]: #text(fill: black, weight: "bold")[Rational agents]
  are agents that do the "right thing" given what they know

- #text(fill: blue, weight: "bold")[Characteristics]: Agents that
  #text(fill: black, weight: "bold")[act rationally] should

  + Operate autonomously
  + Perceive environment
  + Persist over a prolonged time period
  + Adapt to change
  + Create and pursue goals

==== Acting Rationally as Ultimate Goal of AI
<acting-rationally-as-ultimate-goal-of-ai>
- #text(fill: red, weight: "bold")[Question]: Which definition of AI
  best captures what we should build?
  - Acting vs.~Thinking
  - Rational vs.~Human
- #text(fill: black, weight: "bold")[Acting is more fundamental than Thinking]
  - Acting rationally is broader than just thinking rationally
- #text(fill: black, weight: "bold")[Rational is more objective than Human]
  - Rationality can be mathematically defined
  - Human behavior is shaped by evolutionary conditions
- #text(fill: blue, weight: "bold")[Conclusion]: AI should focus on
  #text(fill: black, weight: "bold")[agents acting rationally]

==== Rationally is Not Absolute
<rationally-is-not-absolute>
- #text(fill: red, weight: "bold")[Problem]: AI aims to build agents
  that #text(fill: black, weight: "bold")[do the right thing];, but what is the right thing?

- #text(fill: green, weight: "bold")[Example]: You leave the house and a
  branch strikes you

  - Did you act rationally?
  - Probably

- #text(fill: blue, weight: "bold")[Example]: You cross the street and a
  car knocks you over

  - Did you act rationally?
  - It depends, but probably not

- #text(fill: rgb("#8B00FF"), weight: "bold")[Challenge]: Moral issues
  with self-driving cars

  - Should a car swerve and hit a pedestrian to avoid a frontal crash
    that would kill two people?

==== Problems of a Rational Agent
<problems-of-a-rational-agent>
- #text(fill: red, weight: "bold")[Challenge]: #text(fill: black, weight: "bold")[Probabilistic
  environment]
  - A rational agent aims for
    - The best outcome in a deterministic setup
    - The best expected outcome under uncertainty
- #text(fill: orange, weight: "bold")[Problem]: What does
  #text(fill: black, weight: "bold")["best"] mean? It is determined by the objective function
  - E.g., cost function, sum of rewards, loss function, utility
- #text(fill: green, weight: "bold")[Consideration]: #text(fill: black, weight: "bold")[Omniscience
  vs no-regrets]
  - Best is based on available information, not perfect knowledge
- #text(fill: teal, weight: "bold")[Constraint]: Sometimes #text(fill: black, weight: "bold")[no
  provably correct action] exists
  - Yet, an action must be taken
- #text(fill: rgb("#00FFFF"), weight: "bold")[Limitation]: Even
  #text(fill: black, weight: "bold")[with perfect information] rationality may not be feasible due
  to
  - Cost of acquiring all data (e.g., in medicine)
  - Computational demands
- #text(fill: blue, weight: "bold")[Solution]: #text(fill: black, weight: "bold")["Satisficing"
  (perfect good enough vs perfect)]
  - Acting appropriately given computational constraints

==== Machine Learning: Definitions
<machine-learning-definitions>
- #text(fill: red, weight: "bold")[Question]: How should we define
  machine learning?

- #text(fill: orange, weight: "bold")[Definition]: #emph["Machine
  learning is the field of study that gives computers the ability to
  learn without being explicitly programmed"] (Samuel, 1959)

- #text(fill: green, weight: "bold")[Alternative]: #text(fill: black, weight: "bold")[Machine
  learning] builds machines to do #text(fill: black, weight: "bold")[useful things] without being
  #text(fill: black, weight: "bold")[explicitly programmed]

  - #text(fill: teal, weight: "bold")[Example]: A computer learns to
    play checkers by playing against itself, memorizing positions that
    lead to winning

- #text(fill: rgb("#00FFFF"), weight: "bold")[Formal]: #emph["A computer
  program is said to learn from experience $E$ with respect to some task
  $T$ and some performance measure $P$, if $P \( T \)$ improves with
  experience $E$"] (Mitchell, 1998)

- #text(fill: blue, weight: "bold")[Applications]: Common examples
  include

  - Computer vision
  - Speech recognition
  - Natural language processing

==== Limits of ML Compared to Human Intelligence
<limits-of-ml-compared-to-human-intelligence>
- #text(fill: red, weight: "bold")[Problem]: #text(fill: black, weight: "bold")[AI differs from
  human intelligence]
  - Machines do not learn like humans (e.g., LLMs)
- #text(fill: orange, weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Fragility to
  input variations]
  - ML models fail with slight input distortions
    - Adversarial attacks cause misclassification by altering one pixel
    - A model trained on a video game fails if the screen rotates
      slightly; humans continue effortlessly
- #text(fill: green, weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Lack of
  transfer learning]
  - ML systems cannot apply knowledge across domains without retraining
- #text(fill: teal, weight: "bold")[Challenge]: #text(fill: black, weight: "bold")[Massive data and
  compute requirements]
  - ML requires enormous datasets and computational resources
    - A teenager learns to drive in hours
    - Self-driving systems need billions of compute hours and extensive
      data
- #text(fill: rgb("#00FFFF"), weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Poor
  common sense and reasoning]
  - ML lacks built-in world knowledge and intuitive logic

==== Limits of ML Compared to Human Intelligence (cont.)
<limits-of-ml-compared-to-human-intelligence-cont.>
- #text(fill: red, weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Opaque
  decision-making]
  - Many ML models offer little transparency into decision processes
    - Limits trust, interpretability, and accountability in critical
      applications
- #text(fill: orange, weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Dependence on
  narrow objectives]
  - ML systems excel at optimizing narrow tasks but fail with ambiguous
    goals
    - #text(fill: green, weight: "bold")[Example]: An algorithm
      maximizing user engagement may promote harmful content
- #text(fill: teal, weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Susceptibility
  to bias and data quality]
  - Models inherit and amplify biases in training data
- #text(fill: rgb("#00FFFF"), weight: "bold")[Limitation]: #text(fill: black, weight: "bold")[Lack
  of embodiment and physical interaction]
  - Human cognition is grounded in physical and sensory experience

==== The 3 Machine Learning Assumptions
<the-3-machine-learning-assumptions>
- #text(fill: red, weight: "bold")[Context]: In practice, ML involves
  solving a practical problem by
  - Gathering a dataset
  - Building a statistical model from the dataset algorithmically
- #text(fill: green, weight: "bold")[Definition]: The #text(fill: black, weight: "bold")[three core
  assumptions] of machine learning
  - A #text(fill: black, weight: "bold")[pattern exists]
  - Pattern cannot be #text(fill: black, weight: "bold")[precisely defined mathematically]
  - #text(fill: black, weight: "bold")[Data is available]
- #text(fill: blue, weight: "bold")[Question]: Which assumption is
  #text(fill: black, weight: "bold")[essential];?
  - A pattern exists: If no pattern exists, learning fails
  - Pattern cannot be precisely defined: Even direct solutions can use
    ML
  - Data is available: #text(fill: black, weight: "bold")[Without data, no progress is possible]
    - Data is the most crucial assumption
