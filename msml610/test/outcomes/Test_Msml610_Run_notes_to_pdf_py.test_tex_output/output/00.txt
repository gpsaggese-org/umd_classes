\begin{frame}{Class Projects}
\protect\phantomsection\label{class-projects}
\begin{itemize}
\tightlist
\item
  The project is \emph{``Build \(X\) with \(Y\)''}, where \(X\) is a
  ``use case'' and \(Y\) is a ``technology''

  \begin{itemize}
  \tightlist
  \item
    Study and describe technology \(Y\)
  \item
    Implement a use case \(X\) using the technology \(Y\)
  \item
    Create Jupyter notebooks to demo your project
  \item
    Commit code to GitHub and contribute to open-source repo
  \item
    Write a blog entry
