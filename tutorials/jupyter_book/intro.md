# Tutorials

This book collects the package tutorials in `tutorials/`. Each tutorial
covers one library or tool used in DATA605 and MSML610 and follows the same
layout:

- `README.md`: overview, installation, and links to docs
- `*.API.ipynb`: a tour of the package's native API
- `*.example.ipynb`: an end-to-end example built on top of the API

Notebooks are rendered with their stored outputs and are not re-executed at
build time, since each tutorial depends on a different (and sometimes
conflicting) set of packages.

Pick a tutorial from the navigation to get started.
