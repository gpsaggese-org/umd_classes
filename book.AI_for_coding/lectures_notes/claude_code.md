# Platforms and Integrations
- Claude Code allows selection of platforms and integrations for optimized
  workflows

## Where to Run Claude Code
- Select platform based on work style and project location:
  - **CLI**: Best for terminal workflows and scripting
    - Full features, supports Agent SDK, third-party providers
  - **Desktop**: Ideal for visual reviews and parallel sessions
    - Includes diff viewer and app preview
  - **VS Code**: Works seamlessly within VS Code
    - Features inline diffs and integrated terminal
  - **JetBrains**: For use within JetBrains IDEs
    - Offers diff viewer and selection sharing
  - **Web**: For long-running tasks and offline work
    - Managed by Anthropic, continues running after disconnection
  - **Mobile**: For starting and monitoring tasks away from the computer
    - Allows cloud sessions and remote control for local tasks

## Connect Your Tools
- Integrations enhance Claude's functionality with external services:
  - **Chrome**: Automates browser tasks for testing and form filling
  - **GitHub Actions** / **GitLab CI/CD**: Integrates Claude into CI pipelines
  - **Code Review**: Automatically reviews pull requests
  - **Slack**: Responds to mentions in channels for task management
- Other services can be connected via MCP servers and connectors

## Work When You Are Away From Your Terminal
- Various options allow work when away:
  - **Dispatch**: Send tasks via mobile app to your Desktop
  - **Remote Control**: Control a session from your mobile app or website
  - **Channels**: React to events from chat apps or own servers
  - **Scheduled tasks**: Automate tasks on a set schedule
