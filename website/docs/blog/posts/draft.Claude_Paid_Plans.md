# Understanding Claude Pro and Max Plans

Anthropic offers several subscription tiers for Claude, ranging from Free to Pro and the more powerful Max plans. While many users assume Max provides unlimited access, the reality is a bit more nuanced.

## Claude Pro

Claude Pro costs approximately $20/month and is designed for regular users who need more capacity than the free tier. It provides higher usage limits, priority access during busy periods, and access to the latest Claude models.

## Claude Max

For power users, Anthropic offers two Max tiers:

- **Max 5x** — approximately $100/month
- **Max 20x** — approximately $200/month

The names refer to usage capacity relative to Pro:

- Max 5x = roughly 5× the usage of Pro
- Max 20x = roughly 20× the usage of Pro

## How Usage Limits Work

Unlike services that offer a fixed number of messages per day, Claude uses a dynamic usage system based on factors such as:

- Conversation length
- Number of tokens processed
- Model being used
- File uploads and document size
- Advanced reasoning and coding tasks

As a result, a single large coding session can consume significantly more capacity than dozens of simple chat messages.

## Are Max Plans Unlimited?

No.

Even Max subscribers are subject to:

- Rolling usage windows
- 5-hour session limits
- Weekly usage limits
- Model-specific limits
- Capacity controls during periods of high demand

Anthropic does not publicly disclose the exact quotas.

## Which Plan Should You Choose?

### Free
Best for occasional use and experimentation.

### Pro
Ideal for daily users, writers, students, and most professionals.

### Max 5x
A good fit for developers and researchers who regularly hit Pro limits.

### Max 20x
Designed for heavy users who rely on Claude for many hours every day, especially for coding, analysis, and large-scale projects.

## Final Thoughts

The biggest misconception about Claude Max is that it offers unlimited usage. In reality, it provides substantially larger usage budgets than Pro, but those budgets are still governed by rolling limits and system capacity constraints.

For most users, Pro is sufficient. Max plans primarily benefit those who use Claude as a core productivity or development tool throughout the day.

## Plan vs Metered

Pro plan (subscription)
You pay a flat monthly fee ($20/month, or a bit less if billed annually), and that single subscription covers both Claude.ai (web/desktop/mobile) and Claude Code. With Pro and Max plans, your subscription gives you access to both Claude on the web, desktop, and mobile apps and Claude Code in your terminal in one unified subscription. Usage is governed by a rolling usage allowance rather than per-token billing, and that allowance is shared across Claude and Claude Code, meaning all activity in both tools counts against the same usage limits. If you burn through that allowance, you can wait for it to reset, upgrade to a higher Max tier, or opt in to pay-as-you-go API credits to keep going. ClaudeClaude
Metered API (pay-as-you-go)
Instead of a flat fee, you're billed per token consumed, at the standard published API rates, through a Claude Console account. There's no usage cap built in — you pay for exactly what you use, with full visibility into cost per request, but also no ceiling, so heavy or runaway usage (long autonomous coding sessions, lots of tool calls) can get expensive without anything stopping it short of a workspace spend limit you set yourself.
How they interact in Claude Code specifically
These are genuinely separate billing systems, and an important gotcha: if you have an ANTHROPIC_API_KEY environment variable set on your system, Claude Code will use this API key for authentication instead of your Claude subscription, resulting in API usage charges rather than using your subscription's included usage. So even as a Pro subscriber, you can accidentally end up on metered billing if that variable is set. If you want to use API credits through Claude Code, usage will be billed at standard API rates, distinct from Pro/Max Plan pricing — and Anthropic requires explicit consent before transitioning to API credit usage, so you won't be switched over silently.
