- **CRUD Operations**
- CRUD = Create, Read, Update, Delete

- @Create@
  ```python
  db.collection.insert(<document>)
  db.collection.update(<query>, <update>, {upsert: true})
  ```
  - Upsert = update (if exists) or insert (if it doesn't)
- @Read@
  ```python
  db.collection.find(<query>, <projection>)
  db.collection.findOne(<query>, <projection>)
  ```
- @Update@
  ```python
  db.collection.update(<query>, <update>, <options>)
  ```
- @Delete@
  ```python
  db.collection.remove(<query>, <justOne>)
  ```

- Details [here](https://www.mongodb.com/docs/manual/crud/)

- **Create Operations**
- \textcolor{blue}{\texttt{db.collection}} specifies the collection (like an SQL table) to store the
  document
  ```python
  db.collection.insert(<document>)
  ```
  - Without \textcolor{blue}{\texttt{\_id}} field, MongoDB generates a unique key
    ```python
    db.parts.insert({type: "screwdriver", quantity: 15})
    ```
  - Use \textcolor{blue}{\texttt{\_id}} field if it has a special meaning
    ```python
    db.parts.insert({_id: 10, type: "hammer", quantity: 1})
    ```
- Update 1 or more records in a collection satisfying @query@
  ```python
  db.collection.update(<query>, <update>, {upsert: true})
  ```
- Update an existing record or create a new record
  ```python
  db.collection.save(<document>)
  ```
- A more modern OOP-like syntax than the COBOL / FORTRAN-inspired SQL

- **Read Operations**
- \textcolor{blue}{\texttt{find}} provides functionality similar to \textcolor{blue}{\texttt{SQL SELECT}} command
  ```python
  db.collection.find(<query>, <projection>).cursor
  ```
  with:
    - \textcolor{blue}{\texttt{<query>}} = \textcolor{blue}{\texttt{WHERE}} condition
    - \textcolor{blue}{\texttt{<projection>}} = fields in result set

- \textcolor{blue}{\texttt{db.parts.find({parts: "hammer"}).limit(5)}}
  - Return cursor to handle a result set
  - Can modify the query to impose limits, skips, and sort orders
  - Can specify to return the ‘top' number of records from the result set

- \textcolor{blue}{\texttt{db.collection.findOne(<query>, <projection>)}}

- **More Query Examples**
- Mongo has a functional programming flavor
  - E.g., composing operators, like \textcolor{blue}{\texttt{$or}}

:::columns
::::{.column width=40%}
\footnotesize
@SQL@
```sql
SELECT * FROM users WHERE age>33

SELECT * FROM users WHERE age!=33

SELECT * FROM users
  WHERE name LIKE "%Joe%"

SELECT * FROM users WHERE a=1 and b='q'

SELECT * FROM users WHERE a=1 or b=2

SELECT * FROM foo
  WHERE name='bob' and (a=1 or b=2 )

SELECT * FROM users
  WHERE age>33 AND age<=40
```

::::{.column width=40%}
\footnotesize
@Mongo@
```python
db.users.find({age: {$gt: 33}})

db.users.find({age: {$ne: 33}})

db.users.find({name: /Joe/})

db.users.find({a: 1, b: 'q'})

db.users.find({$or: [{a: 1}, {b: 2}]})

db.foo.find({name: "bob",
  $or: [{a: 1}, {b: 2}]})

db.users.find({'age':
  {$gt: 33, $lte: 40}})
```

- **Query Operators**

![](data605/lectures_source/images/lecture_6_1/lec_6_1_slide_24_image_1.png){width=70%}

- **Update Operations**
- \textcolor{blue}{\texttt{db.collection.insert(<document>)}}
  - Omit the \textcolor{blue}{\texttt{\_id}} field to have MongoDB generate a unique key
    ```mongo
    db.parts.insert({type: "screwdriver", quantity: 15})
    db.parts.insert({_id: 10, type: "hammer", quantity: 1})
    ```
- \textcolor{blue}{\texttt{db.collection.save(<document>)}}
  - Updates an existing record or creates a new record
- \textcolor{blue}{\texttt{db.collection.update(<query>, <update>, {upsert: true})}}
  - Will update 1 or more records in a collection satisfying query
- \textcolor{blue}{\texttt{db.collection.findAndModify(<query>, <sort>, <update>, <new>, <fields>, <upsert>)}}
  - Modify existing record(s)
  - Retrieve old or new version of the record

- **Delete Operations**
- \textcolor{blue}{\texttt{db.collection.remove(<query>, <just\_one>)}}
  - Delete all records from a collection or matching a criterion
  - \textcolor{blue}{\texttt{<just\_one>}} specifies to delete only 1 record matching the criterion
- Remove all records in \textcolor{blue}{\texttt{parts}} with \textcolor{blue}{\texttt{type}} starting with h
  - \textcolor{blue}{\texttt{db.parts.remove(type: /h/ )}}
- Delete all documents in the \textcolor{blue}{\texttt{parts}} collection
  - \textcolor{blue}{\texttt{db.parts.remove()}}

- **MongoDB Features**
- Document-oriented NoSQL store

- Rich querying
  - Full index support (primary and secondary)

- Fast in-place updates

- Agile and scalable
  - Replication and high availability
  - Auto-sharding
  - Map-reduce functionality

- Scale horizontally over commodity hardware
  - Horizontally = add more machines
  - Commodity hardware = inexpensive servers

- **MongoDB vs Relational DBs**
- Keep the functionality that works well in RDBMSs
  - Ad-hoc queries
  - Fully featured indexes
  - Secondary indexes
- Do not offer RDBMS functionalities that don't scale up
  - Long running multi-row transactions
  - ACID consistency
  - Joins
